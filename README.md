# LongShot 滚动长截图

Windows 上的长截图工具：弹出小窗 → 选「自动」或「手动」→ 滚动并拼接成长图 → 保存到 `C:\Users\LXY\Pictures\Screenshots` → 自动退出。

## 使用方法

1. 先切到要截图的目标窗口（浏览器、文档等），把内容滚到顶部。
2. 双击桌面上的 **LongShot.exe**。
3. 二选一：
   - **自动**：工具自己滚动并截图，连续多次滚不动后自动停止。
   - **手动**：工具不滚，你自己慢慢滚动页面，工具在后台记录画面变化；按 **Esc** 结束并拼接。
4. 完成后自动打开输出文件夹并选中图片，进程退出。

自动模式下按 Esc 可中止（已截部分会保存）；手动模式下按 Esc 是完成记录并拼接。记录期间注册 Esc 热键，短按也会保留事件；结束后释放。快捷键被其他程序占用时会提示并取消开始。手动模式记录期间，任务栏托盘区会显示一个图标提示"记录中"。

输出文件名：`LongShot_yyyyMMdd_HHmmss.png`。

## 工作方式

- **截取范围**：优先当前前台窗口的客户区；拿不到时回退主屏工作区（不含任务栏）。
- **自动模式**：SendInput 慢速滚轮，自适应格数；灰度粗匹配 + 1px 精修算出滚动像素，追加新进入画面的行；连续 5 次画面不变时停止。匹配失败先等待重拍，再逐格回滚寻找重叠，恢复失败会说明只保存了部分内容。
- **手动模式**：不发送滚轮、不移动鼠标；每 220ms 截一帧，检测到画面有有效滚动才记录并增量拼接；按 Esc 结束后保存。
- **停止/上限**：自动模式连续 5 次无变化；两种模式都有 18000 像素高度、步数上限。窗口移动、缩放、最小化或失去前台焦点时停止并保存已有内容。
- **固定栏**：检测顶部、底部连续不变的区域，匹配时排除；固定页脚在拼接时移到末尾。浮动按钮、动态广告、嵌套滚动区等复杂页面仍可能影响结果。
- **文件名冲突**：自动加序号（`_1`、`_2`…），不会覆盖。
- **DPI**：声明 DPI 感知，125% 缩放下按物理像素（2560×1440）截图，不会糊。
- **手动模式注意**：请慢慢滚动，保持相邻画面充分重叠。滚动过快后，托盘会提示缓慢往回滚到已记录位置，再继续向下；恢复前不会直接接入无法匹配的画面。结束时仍未衔接会提示只保存了连续记录的部分。

## 构建

需要 Windows 自带的 .NET Framework 4.x 编译器（`csc.exe`）：

```
build.bat
```

产物 `LongShot.exe` 单文件，零第三方依赖；构建脚本会自动复制到桌面。

## 参数

- `--auto`：启动后自动开始自动模式（测试用，成功直接退出、不打开文件夹）。
- `--manual`：启动后自动开始手动模式（测试用）。

## 注意

- **不要直接在 `D:\Code\longshot\` 下双击 exe**：本机该目录被标记为低完整性（DSH 沙箱工作区），从那里启动的进程写不了 `Pictures`，滚轮注入也会被 UIPI 隔离。请使用桌面副本。
- 目标窗口必须自己支持鼠标滚轮滚动；不可滚动的页面会保存当前单屏。
- 开始前确认目标窗口；工具隐藏后会选择当时的前台窗口。启动工具后如果切到其他应用，可能选错截图目标。

## 回归测试

使用 PowerShell 7 运行，无需操作桌面或第三方测试框架：

```powershell
pwsh -File .\test\run.ps1
```

- 原有 9 项位移测试：6 个滚动量（60–700px）、相同帧、底部重复帧、无关帧；无关帧必须判为无效。
- 新增 14 项回归：逐像素验证拼接连续性、固定顶栏/页脚、非 4px 对齐固定栏、高度截断、快速滚动后恢复、向上滚动、未恢复即结束、自动回滚、无滚动页面、无法恢复、目标变化、Esc、截图异常及 PNG 编解码。
- 自动与手动记录循环使用可替换的帧来源，测试运行实际记录和拼接逻辑，核对完整输出像素而非仅检查高度。

仓库原有 `demo_2560x8750.png` 是旧版产物，存在内容覆盖和透明尾部，不能作为新版正确性的验证依据。

2026-10-24 桌面验证（125% 缩放，受控 TestTarget 窗口）：

- 自动模式：7000 逻辑像素内容 → 2560×8750 PNG；70 个主色带完整，间距 124–126px，检查列无透明行，保存后正常退出。
- 手动模式：从 scroll=300 记录到 scroll=600，短按 Esc → 2560×1726 PNG（1351px 客户区 + 375px 新内容），检查列无透明行。
- 浏览器平滑滚动、动态页面和多显示器不同 DPI 尚未完成新版桌面验证。
