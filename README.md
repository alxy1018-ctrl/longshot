# LongShot 滚动长截图

Windows 上的长截图工具：弹出小窗 → 选「自动」或「手动」→ 滚动并拼接成长图 → 保存到 `C:\Users\LXY\Pictures\Screenshots` → 自动退出。

## 使用方法

1. 先切到要截图的目标窗口（浏览器、文档等），把内容滚到顶部。
2. 双击桌面上的 **LongShot.exe**。
3. 二选一：
   - **自动**：工具自己滚动并截图，连续多次滚不动后自动停止。
   - **手动**：工具不滚，你自己慢慢滚动页面，工具在后台记录画面变化；按 **Esc** 结束并拼接。
4. 完成后自动打开输出文件夹并选中图片，进程退出。

自动模式下按 Esc 可中止（已截部分会保存）；手动模式下按 Esc 是完成记录并拼接。手动模式记录期间，任务栏托盘区会显示一个图标提示"记录中"。

输出文件名：`LongShot_yyyyMMdd_HHmmss.png`。

## 工作方式

- **截取范围**：优先当前前台窗口的客户区；拿不到时回退主屏工作区（不含任务栏）。
- **自动模式**：SendInput 慢速滚轮，每步约 1/3 屏并自适应格数；灰度粗匹配 + 1px 精修算出滚动像素，只追加每帧底部新进入画面的行；连续 5 次无有效位移判定到底。
- **手动模式**：不发送滚轮、不移动鼠标；每 220ms 截一帧，检测到画面有有效滚动才记录并增量拼接；按 Esc 结束后保存。
- **停止/上限**：自动模式连续 5 次无变化；两种模式都有 18000 像素高度、步数上限和窗口尺寸变化检测兜底。
- **文件名冲突**：自动加序号（`_1`、`_2`…），不会覆盖。
- **DPI**：声明 DPI 感知，125% 缩放下按物理像素（2560×1440）截图，不会糊。
- **手动模式注意**：请慢慢滚动——单帧位移超过约 0.85 屏时可能匹配失败、跳过该段；往回滚的帧会被忽略。

## 构建

需要 Windows 自带的 .NET Framework 4.x 编译器（`csc.exe`）：

```
build.bat
```

产物 `LongShot.exe` 单文件，零第三方依赖；构建脚本会自动复制到桌面。

## 参数

- `--auto`：启动后自动开始自动模式（测试用，成功直接退出、不打开文件夹）。
- `--manual`：启动后自动开始手动模式（测试用）。

## 注意

- **不要直接在 `D:\Code\longshot\` 下双击 exe**：本机该目录被标记为低完整性（DSH 沙箱工作区），从那里启动的进程写不了 `Pictures`，滚轮注入也会被 UIPI 隔离。请使用桌面副本。
- 目标窗口必须自己支持鼠标滚轮滚动；不可滚动的页面会保存当前单屏。
- 手动模式的真实窗口滚动记录未做自动验证（开发时前台被其他窗口占用），第一次用请留意结果，有问题反馈。

## 已验证

- 离线位移检测：6 个滚动量（60–700px）1px 内准确；相同帧/到底重复帧报 0；无关帧无效。
- 自动模式端到端：7000px 内容 → 20 步有效位移 → 输出 **2560×8750** 长图，总高与内容总高一致。
- 按钮点击链路：BM_CLICK 触发开始 → 窗口隐藏 → 截图 → 保存 → 退出，全链路通过。
- 新界面：左「自动」右「手动」、标题居中、说明文字不截断（物理截图确认）。
- 手动模式：记录/拼接逻辑与自动模式共用 Matcher 与保存代码，界面已验证；未做真实窗口的滚动记录验证。
